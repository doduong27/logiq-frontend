# LogIQ Frontend Repository (logiq-frontend)

Kho lưu trữ ứng dụng Web Dashboard giao diện người dùng của LogIQ, xây dựng bằng React, TypeScript, TailwindCSS và Lucide Icons.

---

## 🚀 Khởi Chạy Local Dev

1. Cài đặt dependencies:
   ```bash
   npm install
   ```
2. Khởi chạy dev server:
   ```bash
   npm run dev
   ```
   Ứng dụng sẽ chạy tại: [http://localhost:3000](http://localhost:3000)

---

## 📦 Các Tính Năng Chính
- **Realtime Log Stream**: Theo dõi luồng log trực tiếp với phân loại màu sắc (INFO, WARNING, ERROR, CRITICAL).
- **Incident & Anomaly Triage**: Danh sách sự cố gom cụm lỗi, theo dõi số lần lặp và kết luận chẩn đoán AI (RCA).
- **Metrics Overview**: Thống kê tổng log, số lượng lỗi, tỷ lệ lỗi theo thời gian thực.
